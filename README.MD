## ▶️ Cara Menjalankan Program

Pastikan compiler C++ seperti `g++` sudah terpasang.

### 1. Clone repository

```bash
git clone <URL-REPOSITORY>
```

Ganti `<URL-REPOSITORY>` dengan alamat repository GitHub ini.

### 2. Masuk ke folder praktikum

```bash
cd "praktikum daspro"
```

### 3. Masuk ke folder pertemuan

Contoh untuk pertemuan kedua:

```bash
cd "pertemuan ke 2"
```

### 4. Kompilasi program

Contoh untuk file `if_else.cpp`:

```bash
g++ if_else.cpp -o if_else
```

### 5. Jalankan program

Di Linux atau Ubuntu:

```bash
./if_else
```

Sesuaikan nama file dengan program yang ingin dijalankan.
